# Farzana — Responsive Portfolio

A responsive personal portfolio website created for the CodeNova Batch 01 Frontend Development internship.

## Features
- Semantic HTML5 structure
- Responsive mobile, tablet and desktop layouts
- CSS Flexbox and Grid
- Accessible mobile navigation
- Dark/light theme toggle
- Smooth section navigation
- Skills and project cards
- Contact form interaction
- Mobile-friendly design

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript

## Project Structure
- `index.html` — page structure
- `style.css` — responsive styling and themes
- `script.js` — navigation, theme toggle and form interaction

## Run Locally
Open `index.html` in a browser.

## Deployment
This project can be deployed free using GitHub Pages, Vercel, or Netlify.
